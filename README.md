# Amnezia Control

Self-hosted панель управления WireGuard и AmneziaWG на том же VPS, где работает VPN.

## Возможности

- интерактивная установка на чистый Ubuntu/Debian сервер;
- русский и английский язык установщика;
- создание администратора панели;
- доступ по IP и домену, HTTPS через Certbot;
- WireGuard и AmneziaWG через локальные команды `wg`/`awg`;
- версии протокола 1.5, 2.0, 3.0 и 3.1 в профиле клиента;
- автоматические ключи, `.conf` и QR-коды;
- имена `User 01`, `User 02` и собственные имена до 30 символов;
- описание, лимит трафика, срок действия, отключение и возобновление;
- импорт существующих конфигураций `.conf`;
- резервная копия, обновление, проверка состояния и полное удаление;
- ручной endpoint для relay/резервного VPS или домена.

## Установка на чистый VPS

Поддерживаются Ubuntu 22.04/24.04 и Debian 12/13 с root-доступом. На сервере выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/dagmagnat/amnezia-control/main/scripts/install.sh -o install.sh
chmod +x install.sh
sudo ./install.sh
```

Установщик спросит язык, логин, пароль, порт панели и домен (домен можно пропустить и оставить IP). Он установит Python, Nginx, WireGuard, AmneziaWG-пакет когда он доступен для ОС, создаст systemd-сервис, базу данных, серверный интерфейс и администратора.

После завершения откройте адрес, который напечатает установщик.

> Если репозиторий имеет другое имя, замените URL на адрес своего GitHub-репозитория. Для установки из загруженного архива используйте `sudo ./scripts/install.sh --source /path/to/project`.

## Управление

```bash
sudo /opt/amnezia-control/scripts/update.sh
sudo /opt/amnezia-control/scripts/status.sh
sudo /opt/amnezia-control/scripts/backup.sh /root/amnezia-control-backup.tar.gz
sudo /opt/amnezia-control/scripts/uninstall.sh
```

`uninstall.sh` сначала просит подтверждение. Резервные копии и конфигурации VPN не удаляются без явного подтверждения.

## WireGuard и AmneziaWG

Установщик проверяет наличие `wg` и `awg`. WireGuard использует стандартный интерфейс `wg0`, AmneziaWG — `awg0`. Для AmneziaWG доступны параметры соответствующей версии; параметры 3.1 (`S1-S4`, `Jc`, `Jmin`, `Jmax`, `H1-H4`, `HeaderProtectionKey`, `ContentPaddingAddition`) передаются в конфигурацию только если установленный `awg` их поддерживает.

Версия 1.5/2.0/3.0/3.1 — это профиль конфигурации. Нельзя одновременно загрузить несколько несовместимых kernel-модулей в один интерфейс. Панель показывает фактическую доступность движка и не обещает неподдерживаемую комбинацию.

## Relay, домен и запасной сервер

В профиле клиента поле `Endpoint` можно указать как IP, домен или нестандартный порт. Поэтому российский relay и зарубежный origin настраиваются вручную: DNS направляет домен на relay, а relay пересылает UDP-порт WireGuard/AmneziaWG дальше. Панель не меняет DNS и не включает произвольный forwarding автоматически.

Для резервного VPS создайте второй сервер в разделе «Серверы» и вручную выпустите клиентские конфигурации с его endpoint. Автоматический failover не включён, чтобы не менять маршрутизацию без контроля администратора.

## Импорт

В разделе «Импорт» можно загрузить `.conf`. Импорт сохраняет имя, адрес, endpoint и поддерживаемые параметры. Приватный ключ не отправляется наружу и хранится только в SQLite на VPS. Перед импортом сделайте резервную копию.

## Команды для клиентского файла

Панель выдаёт `.conf` и QR-код. Клиентское приложение можно скачать из официальных источников:

- [AmneziaWG для Windows](https://github.com/amnezia-vpn/amneziawg-windows-client/releases)
- [AmneziaWG Tools](https://github.com/amnezia-vpn/amneziawg-tools/releases)
- [Официальная документация AmneziaWG](https://docs.amnezia.org/documentation/amnezia-wg/)

## Безопасность

- не публикуйте `.env`, SQLite и `/etc/wireguard` в GitHub;
- после установки смените пароль администратора;
- ограничьте SSH и web-панель firewall-правилами;
- включите HTTPS для домена;
- не передавайте приватные ключи в issue, логи или чат.
