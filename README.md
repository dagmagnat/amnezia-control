# Amnezia Control

Панель управления конфигурациями **AmneziaWG 3.1** и обычного **WireGuard**.

Проект рассчитан на дальнейшее подключение к VPS: создание клиентов, выдача конфигураций `.conf`, QR-кодов, лимитов трафика и сроков действия.

## Что сейчас работает

- вход в панель в демонстрационном режиме;
- создание одного или нескольких клиентов;
- автоматические имена `User 01`, `User 02` и далее;
- собственный префикс имени клиента;
- выбор AmneziaWG 3.1 или WireGuard;
- лимит трафика и срок действия;
- описание клиента;
- поиск клиентов;
- адаптивный интерфейс для компьютера и телефона.

> Текущая версия интерфейса — frontend MVP. Генерацию реальных ключей и конфигураций подключим к VPS на следующем этапе.

## Быстрый запуск интерфейса

Требуется Python 3.

```bash
python -m http.server 4173 --directory dist
```

Откройте в браузере:

```text
http://localhost:4173
```

Демо-доступ:

```text
Логин: admin
Пароль: amnezia-demo
```


## План подключения VPS

1. Установить AmneziaWG или WireGuard на сервере.
2. Добавить backend API панели.
3. Хранить серверные ключи и конфигурации только на VPS.
4. Реализовать создание peer, отзыв доступа и повторную выдачу конфигурации.
5. Добавить импорт существующих `.conf` и резервное копирование.
6. Подключить домен и HTTPS.

Не храните приватные ключи и пароли от VPS в публичном репозитории.
