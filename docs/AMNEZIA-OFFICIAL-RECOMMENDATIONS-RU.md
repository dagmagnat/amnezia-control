# AmneziaWG: проверенные рекомендации

Обновлено 18 ноября 2026 года. Параметры работающих VPN-серверов не изменялись. С версии 0.6.2 официальный I1 автоматически добавляется при скачивании и генерации QR для созданных панелью клиентов AmneziaWG 3.1, если в профиле нет своего I1.

## I1 из официальной инструкции

Указанная пользователем строка есть в [инструкции Amnezia по устранению неполадок](https://docs.amnezia.org/troubleshooting/self-hosted-amneziawg-not-working/). Она сохранена целиком в [official-I1-Amnezia.txt](official-I1-Amnezia.txt), одной строкой, без HTML-экранирования. В поле I1 вставляется только значение; в клиентском `.conf` — строка `I1 = значение` внутри `[Interface]`.

Для AmneziaWG 3.1 инструкция предлагает сначала заменить I1 на одном устройстве: это не требует новых пользователей или ключей. Общий серверный раздел AmneziaVPN имеет другое поведение: сохранение настроек переустанавливает контейнер и требует перевыпуска доступов. Эти действия нельзя переносить на работающий сервер без оценки последствий. Сам текст инструкции описывает AmneziaVPN Self-hosted; интерфейс отдельного приложения AmneziaWG отличается.

Строка не гарантирует будущую доступность: инструкция допускает блокировку сигнатуры и проверку другого варианта. В ней также предлагается сначала проверить доступность Интернета и сервера. Порт ниже 9999 предложен в сценарии переустановки через AmneziaVPN; это не основание менять порт уже работающих импортированных клиентов.

## Что проверено в нашей сборке

Значение проходит текущий валидатор панели. Расчёт четырёх CPS-блоков: 291 байт фиксированных данных, 640 случайных, 269 фиксированных и 64 случайных — всего 1264 байта. Это размер данного CPS-пакета, а не настройка MTU.

В 156 исходных клиентских файлах проверенного импорта I1 присутствует и сохранён; он отличается от приведённого сейчас официального примера. До 0.6.2 официальный I1 был сохранён только в документации. В 0.6.2 он подключён к клиентскому генератору 3.1. Собственный I1 профиля и исходные импортированные файлы сохраняются, включая отсутствие I1 в исходном импорте. Наши значения по умолчанию не следует считать точной копией текущих настроек установщика AmneziaVPN.

Для проверки сделайте отдельную копию клиентского файла, замените только I1 и проверьте соединение на нужном операторе. Исходный профиль сохраните. Выбор отдельной версии в панели позволяет оставить старый доступ рабочим. Уже скачанные файлы автоматически не обновляются.

## Совместимость параметров

В [описании протокола](https://docs.amnezia.org/documentation/amnezia-wg/) указано: CPS-пакеты I1–I5 предшествуют рукопожатию; пример синтаксиса не обязательно является рабочей сигнатурой. При Header Protection нужны S1–S4 не меньше 12 и ключ HeaderProtectionKey; рекомендованы H1–H4 = 1, 2, 3, 4. Для RandomTrailers рекомендованы одинаковые S1–S4. В наших новых профилях 3.1 эти ограничения учтены. Поддержка версии необходима и на клиенте.

S/H и HeaderProtectionKey нельзя произвольно менять только на одной стороне. В редакторе общего профиля Amnezia Control изменение параметров требует подтверждения перевыпуска файлов. Для локальной проверки I1 используйте настройки конкретного устройства или копию его `.conf`, а не изменение всего профиля.

Если подходящей сигнатуры нет, у Amnezia есть [инструкция поиска CPS-сигнатуры](https://docs.amnezia.org/documentation/instructions/amneziawg-signature/): выбирают начальный UDP-пакет нужного протокола, например QUIC, и оформляют его данные как CPS. Случайный набор байтов не равнозначен корректной имитации.
