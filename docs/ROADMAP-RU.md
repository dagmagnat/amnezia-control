# План функций Amnezia Control

Согласовано 11 ноября 2026. Из исходного списка исключены пункты **14, 15, 16, 17, 18, 24, 25**: 2FA, уведомления, webhooks, отдельный аналитический дашборд, отчёты/экспорт, темы, API-ключи/Swagger. Существующее API панели и графики из пунктов 1–2 сохраняются. Языки только русский и английский.

Изменения вводятся последовательно: проверка отдельно, резервная копия, затем обновление панели с сохранением VPN-конфигураций.
